# Game audio assets

- `game_audio.mp3` is the theme track supplied in the project as `Game  Audio.mp3`; it is 67.004 seconds and loops in the app. Its reuse rights were not included with the file, so confirm the rights before distributing the app.
- `tap.wav`, `select.wav`, `correct.wav`, `incorrect.wav`, `start.wav`, and `victory.wav` are original synthesized effects generated by `tool/generate_audio_effects.py` for this project.

Background music and touch effects have separate, enabled-by-default settings stored locally with SharedPreferences. Gameplay and audio work without network access.
