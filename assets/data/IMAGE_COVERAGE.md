# Image coverage report

Updated with the structured category dataset. Character portraits are not bundled with the app. Random / Mixed samples only use enabled items from enabled categories.

The Pokémon items below have predefined HTTPS URLs to the PokeAPI sprites repository's `official-artwork` directory, matched by Pokédex ID. The repository documents that it hosts Pokémon sprites; network availability and continued URL availability are not guaranteed. The remaining catalog items have no image URL because this project does not contain verified source URLs for them. They display the name fallback until an image source is verified and added by a maintainer.

Pokémon source: <https://github.com/PokeAPI/sprites>. URL pattern: `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/{id}.png`.
