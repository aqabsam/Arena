# Character Image URL Source Review

## Result

- Current catalog items: 421 across 35 playable categories, plus Random / Mixed.
- Predefined image URLs: 11 Pokémon official-artwork paths from the [PokeAPI sprites repository](https://github.com/PokeAPI/sprites), matched by Pokédex ID.
- Other catalog entries with verified URLs: 0. The existing project did not include source URLs for its local Marvel art or identified image sources for the remaining entries, so no URLs were guessed.
- Users cannot add or upload character images. Adding a URL requires a maintainer to verify the mapping and update `assets/data/categories.json`.

These remote images require an internet connection unless Flutter still has them in its in-memory image cache. The app does not persist image bytes for offline use.
